## Failed runs — all 3 baseline (no-KD) students

| Job | Model | Override |
|---|---|---|
| 26729 | EfficientNet-B0 | `student=efficientnet_b0 training=baseline` |
| 26730 | MobileNetV3-Large | `student=mobilenetv3_large training=baseline` |
| 26731 | MobileViT-S | `student=mobilevit_s training=baseline` |

All three died immediately after loading the teacher checkpoint with the same Hydra error:

```
omegaconf.errors.ConfigAttributeError: Missing key distillation
    full_key: training.distillation
```

### Root cause

The student trainer unconditionally reads `cfg.training.distillation`, but
[configs/training/baseline.yaml](../configs/training/baseline.yaml) does not define that key,
so any `training=baseline` override crashes before the first epoch.

### Fix options

- Guard the lookup in [scripts/train_student.py](../scripts/train_student.py) /
  [src/training/kd_trainer.py](../src/training/kd_trainer.py) behind `if cfg.training.use_kd:`.
- Or add a stub `distillation:` block to `configs/training/baseline.yaml` so the key
  resolves (kept-but-unused) when KD is off.

Until this is fixed, the KD-vs-baseline comparison required by the experiment design
(3 arch × 2 KD conditions × 5 folds = 30 runs) cannot run for the baseline arm.
